# Prompt 05 — JavaScript tương tác

Chỉ triển khai hoặc sửa JavaScript thuần cho: menu mobile; sticky header state; FAQ accordion; smooth navigation có tôn trọng reduced motion; form validation phía client; video visibility control.

Không dùng thư viện ngoài nếu chưa cần. Progressive enhancement: nội dung vẫn đọc được khi JavaScript tắt. Đóng menu bằng Escape và click ngoài; quản lý focus hợp lý; FAQ dùng aria state; không giả lập gửi form thành công nếu chưa có endpoint. Nếu chưa có backend, hiển thị trạng thái demo rõ ràng.

Video: muted, playsInline, loop; pause khi ngoài viewport; không ép autoplay khi `prefers-reduced-motion: reduce` hoặc Save-Data được bật. Không thêm animation làm giảm khả năng đọc.
