# Prompt 07 — QA và sửa lỗi cuối

Kiểm thử landing page như một QA frontend. Không thêm feature mới.

Kiểm tra: link điều hướng; menu mobile; FAQ; form; keyboard-only; focus; reduced motion; video fallback; ảnh lỗi; console error; HTML semantics; responsive; contrast; layout shift; nội dung theo guardrail; title/meta description; trạng thái khi JS tắt.

Chạy preview thật trong browser và cung cấp screenshot desktop/mobile. Sửa mọi lỗi chắc chắn. Với điểm chưa thể kiểm tra do thiếu endpoint hoặc asset, ghi rõ blocker và vị trí. Kết quả cuối gồm: lỗi đã sửa; lỗi còn lại; hướng tái kiểm thử.
