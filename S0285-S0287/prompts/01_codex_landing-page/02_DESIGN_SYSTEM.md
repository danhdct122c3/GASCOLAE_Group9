# Prompt 02 — Thiết kế hệ giao diện

Audit CSS hiện tại và chuẩn hóa thành design system sáng, hiện đại, phù hợp rừng + LiDAR + GIS. Giữ cảm giác thoáng và sáng của template Wix.

Tạo CSS variables cho màu, typography, spacing, radius, shadow, container và transition. Dùng primary `#12735A`; nền `#F2FAF7`; data blue `#287A96`; lime `#9CF06A` chỉ chiếm khoảng 5% điểm nhấn. Tránh giao diện xanh lá môi trường đại trà, glassmorphism dày, quá nhiều card và icon chiếc lá.

Tiêu đề lớn, editorial; nội dung dễ đọc; IBM Plex Mono chỉ dùng cho nhãn dữ liệu. Dùng border mảnh và shadow nhẹ. Bảo đảm màu chữ/nền có độ tương phản tốt. Không thay nội dung hoặc cấu trúc section trong task này. Hoàn tất bằng bảng liệt kê token và nơi đang sử dụng.
